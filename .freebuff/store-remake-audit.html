Bug #1: \u2192 como texto literal nas versões CRÍTICO

Nas screenshots, o Downloads mostra 1.18.21 \u2192 1.18.25 em vez de 1.18.21 → 1.18.25

// StoreRemakePage.xaml.cs — PopulateHomeSections() - HeroMainVersion.Text = main.HasUpdate ? $"{main.Version} \u2192 {main.AvailableVersion}" : main.Version; + HeroMainVersion.Text = main.HasUpdate ? $"{main.Version} → {main.AvailableVersion}" : main.Version; // ⚠️ \u2192 é sintaxe C# dentro de @"" (raw string), mas interpolate string "" NÃO interpola \u // Mesmo bug nas linhas 1035, 1045, 1120
Causa raiz: Em C#, $"\u2192" não interpola o Unicode escape — ele é tratado como caracteres literais \, u, 2, 1, 9, 2. A sintaxe correta é $"{(char)0x2192}" ou simplesmente colar o caractere → direto. Este bug afeta o Hero card e os app cards na Home.
User vê "1.18.21 \u2192 1.18.25"
→
C# $"\u2192" não é Unicode
→
Fix: usar → direto ou (char)0x2192

Afeta 4 linhas: L1023, L1035, L1045, L1120 no .cs
